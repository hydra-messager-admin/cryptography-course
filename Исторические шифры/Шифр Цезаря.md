Смысл шифра в замене каджой буквы текста на другую букву, находящуюся на фиксированное число позиций левее/правее нее в алфавите.

###### Принцип работы: 
(А -> Г, Б -> Д)

###### Пример: 
-  исходный текст: ПРИВЕТ
-  результат:  ТУЛГЗФ

###### Формула для английского алфавита из 26 букв:
  $$y = (x + k) (mod 26)$$

> [!info] Параметры шифра Цезаря:
> * **x** — позиция исходной буквы (начиная с 0)
> * **y** — позиция зашифрованной буквы
> * **k** — шаг сдвига (ключ)
> * **mod 26** — модуль 26 (остаток от деления; при достижении 26-й позиции сбрасывается в 0, возвращая нас к букве A)
###### Код на Python:

```
ALPHABET_RU = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя"
MOD_GEN = len(ALPHABET_RU)  # 33

def caesar_cipher(text, shift, decrypt=False):
    result = []
    # Если дешифруем, сдвиг идет в обратную сторону
    actual_shift = -shift if decrypt else shift
    
    for char in text:
        is_upper = char.isupper()
        char_lower = char.lower()
        
        if char_lower in ALPHABET_RU:
            idx = ALPHABET_RU.index(char_lower)
            # Формула сдвига с остатком от деления
            new_idx = (idx + actual_shift) % MOD_GEN
            new_char = ALPHABET_RU[new_idx]
            result.append(new_char.upper() if is_upper else new_char)
        else:
            result.append(char)
            
    return "".join(result)

# --- Пример использования ---
message = "ПРИВЕТ"
key = 3

encrypted = caesar_cipher(message, key)
decrypted = caesar_cipher(encrypted, key, decrypt=True)

print(f"Оригинал: {message}")
print(f"Зашифровано Цезарем: {encrypted}")
print(f"Расшифровано: {decrypted}")

```


###### Итог:

Шифр Цезаря в настоящее время считается очень слабым из-за маленького количества вариаций ключей, однако он служит онсновой для более сложных шифров, таких как [[Шифр Виженера]] .
