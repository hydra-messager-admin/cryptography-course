- это шифр, при котором элементы исходного текста меняют свое местоположение по определенному правилу, но сами остаются неизменными.

###### Пример для шифрования:
-  ПРИВЕТ_МИР
###### Ключ: 
-  КОД
###### Таблица:

-  П Р И В
   Е Т _ М
   И Р Х Х
  (пустые места заполняем Х)

##### 1.  Простая табличная перестановка

-  1-й столбец: П Е И
-  2-й столбец: Р Т Р
-  3-й столбец: И _ Х
-  4-й столбец: В М Х
- Результат: ПЕИРТРИ_ХВМХ

##### 2. Одиночная перестановка по ключу

1) Берем наш ключ **КОД** и нумеруем буквы по алфавиту. Получилось 2, 3 ,1.
2) Записываем текст в таблицу шириной 3, по длине ключа

| К   | О   | Д   | <-  | Ключ               |
| --- | --- | --- | --- | ------------------ |
| 2   | 3   | 1   | <-  | Порядок считывания |
| П   | Р   | И   |     |                    |
| В   | Е   | Т   |     |                    |
| М   | И   | Р   |     |                    |

3) Записываем резульат в правильном порядке:
$$
	ИТРПВВМРЕИ
$$

##### 3. Математическая формула

$$y = (x \pmod C) \cdot R + \lfloor x / C \rfloor$$

> [!info] Обозначения букв:
> * x — исходный индекс буквы в тексте (начиная с 0)
> * y — новый индекс буквы в зашифрованной строке
> * C — количество столбцов таблицы (*Columns* / Ширина)
> * R — количество строк таблицы (*Rows* / Высота)
> * $(x\pmod C$ — остаток от деления на C (в коде: `x % C`)
> * $\lfloor x / C \rfloor)$ — деление нацело (в коде: `x // C`)


##### 4. Код на Python:

```
import math

def columnar_transposition_encrypt(text, key):
    # Убираем пробелы, чтобы они не ломали структуру (частая практика для этого шифра)
    text = text.replace(" ", "")
    key_len = len(key)
    
    # 1. Определяем порядок чтения столбцов на основе алфавитного порядка букв ключа
    # Пример для "КОД": sorted_key = [('Д', 2), ('К', 0), ('О', 1)]
    key_with_indices = list(enumerate(key))
    # Сортируем по букве, сохраняя исходный индекс столбца
    sorted_by_char = sorted(key_with_indices, key=lambda x: x[1])
    # Получаем финальный порядок индексов (например, [2, 0, 1])
    col_order = [item[0] for item in sorted_by_char]
    
    # 2. Дописываем текст «Х», чтобы он ровно делился на длину ключа
    num_rows = math.ceil(len(text) / key_len)
    total_chars = num_rows * key_len
    text = text.ljust(total_chars, 'Х')
    
    # 3. Формируем матрицу (строки)
    matrix = [text[i:i + key_len] for i in range(0, len(text), key_len)]
    
    # 4. Считываем столбцы в правильном порядке
    result = []
    for col_idx in col_order:
        for row in matrix:
            result.append(row[col_idx])
            
    return "".join(result)

# --- Пример использования ---
message = "ПРИВЕТ МИР"
secret_key = "КОД"

encrypted = columnar_transposition_encrypt(message, secret_key)
print(f"Оригинал:   {message}")
print(f"Ключ:       {secret_key}")
print(f"Зашифровано:{encrypted}") # Выведет ИТРПВМРЕИ
```

-  В алгоритме симметричного шифрования есть два обязательных действия: сдвиг строк и перемешивание столбцов. Это та же табличная перестановка, но доведенная до идеала.
