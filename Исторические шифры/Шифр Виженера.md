 -- это метод шифрования текста с использованием ключевого слова, которое задает последовательность разных сдвигов Цезаря. В отличие от обычного [[Шифр Цезаря| шифра Цезаря]], где сдвиг всегда одинаковый, здесь каждая буква шифруется со своим смещением.

###### Принцип работы с ключом **БВГ**:
* первая буква сдвигается на **Б** (шаг 1): А ➔ Б
* вторая буква сдвигается на **В** (шаг 2): Б ➔ Г
* третья буква сдвигается на **Г** (шаг 3): В ➔ Е
###### Пример:
-  исходный текст: ПРИВЕТ
-  ключ: РПОИРА
-  результат: ААЧКХТ

###### Формула для каждой буквы:

$$y_{\text{  i}} = (x_{\text{ i}} + k_{\text{ i}}) \pmod N$$

> [!info] Параметры шифра Виженера:
> * $x_i$ — исходная буква открытого текста
> * $y_i$ — зашифрованная буква (символ шифротекста)
> * $k_i$ — буква ключа (индивидуальный сдвиг для этого шага)
> * $\pmod N$ — модуль (мощность алфавита, для русского языка $N = 33$)

###### Код на Python:

```
ALPHABET_RU = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя"
MOD_GEN = len(ALPHABET_RU)  # 33

def vigenere_cipher(text, key, decrypt=False):
    result = []
    key_lower = key.lower()
    # Переводим буквы ключа в их числовые индексы
    key_indices = [ALPHABET_RU.index(k) for k in key_lower if k in ALPHABET_RU]
    
    if not key_indices:
        raise ValueError("Ключ должен содержать русские буквы!")
        
    key_len = len(key_indices)
    key_ptr = 0  # Счётчик для перемещения по ключу
    
    for char in text:
        is_upper = char.isupper()
        char_lower = char.lower()
        
        if char_lower in ALPHABET_RU:
            idx = ALPHABET_RU.index(char_lower)
            current_key_shift = key_indices[key_ptr % key_len]
            
            # Направление сдвига: плюс для шифрования, минус для дешифрования
            shift = -current_key_shift if decrypt else current_key_shift
            new_idx = (idx + shift) % MOD_GEN
            
            new_char = ALPHABET_RU[new_idx]
            result.append(new_char.upper() if is_upper else new_char)
            key_ptr += 1  # Ключ продвигается только на буквах текста
        else:
            result.append(char)
            
    return "".join(result)

# --- Пример использования ---
message = "ПРИВЕТ"
vigenere_key = "РПОИРА"

encrypted = vigenere_cipher(message, vigenere_key)
decrypted = vigenere_cipher(encrypted, vigenere_key, decrypt=True)

print(f"Оригинал: {message}")
print(f"Ключ:     {vigenere_key}")
print(f"Зашифровано Виженером: {encrypted}")  # Выведет ААЧКХТ
print(f"Расшифровано:          {decrypted}")
```

###### Итог:

-  ==Шифр *Виженера*==  довольно  устойчив к простому частотному анализу, его стойкость напрямую зависит от длины ключа и текста, который надо зашифровать. 
 -  Если длина ключа меньше длины текста, то ключ повторяется. Это позволяет вычислить длину ключа, анализируя повторяющиеся группы символов в тексте, а затем разбить текст на несколько независимых частей и взломать  каждую  классическим частотным анализом.
 - Для абсолютной устойчивости нужно сделать ключ случайным, никогда не использовать его дважды, а также сделать его хотя бы равным по длине тексту.
