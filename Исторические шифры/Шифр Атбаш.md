-  шифр, шифрующий текст методом отражения алфавита ( первая буква - последняя буква, вторая буква - предпоследняя, ... ). Процесс шифрования и дешифрования абсолютно идентичен, алгоритм менять не надо.
###### Принцип работы:
- А ⇄ Я
- Б ⇄ Ю
- В ⇄ Э
- ...
###### Пример:
-  Исходный текст: ==ПРИВЕТ==
-  Результат: ==РКИЫЭТ==

###### Формула:

$$y = (N - 1)-x$$

> [!info] Параметры шифра Атбаш:
> * **x** — позиция исходной буквы
> * **y** — позиция зашифрованной буквы
> * **N** — количество букв в алфавите ( для русского языка $N = 33$ )

###### Код на Python:

```
ALPHABET_RU = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя"

def atbash_cipher(text):
    result = []
    
    for char in text:
        is_upper = char.isupper()
        char_lower = char.lower()
        
        if char_lower in ALPHABET_RU:
            idx = ALPHABET_RU.index(char_lower)
            # Формула зеркального отражения индекса
            new_idx = len(ALPHABET_RU) - 1 - idx
            new_char = ALPHABET_RU[new_idx]
            result.append(new_char.upper() if is_upper else new_char)
        else:
            result.append(char)  # Пробелы и знаки препинания не трогаем
            
    return "".join(result)

# --- Пример использования ---
message = "ПРИВЕТ"

# Для Атбаша одна и та же функция и шифрует, и расшифровывает
encrypted = atbash_cipher(message)
decrypted = atbash_cipher(encrypted)

print(f"Оригинал: {message}")
print(f"Зашифровано Атбашем: {encrypted}") # Выведет РКИЫЭТ
print(f"Расшифровано обратно: {decrypted}")
```
